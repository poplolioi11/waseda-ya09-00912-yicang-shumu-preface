# 醫藏書目序（早稻田大學圖書館 ヤ09 00912）

*Yi cang shu mu xu [Preface to the Catalogue of Medical Books]*

陳懿典署名的〈醫藏書目序〉討論佛藏、道藏、史志與醫書分類的關係，也記述殷方叔如何蒐羅、分類並評論醫籍。這份資料可用於檢索這篇序文中的書目術語與人物，並逐欄回到手稿核對。

本版收第一篇序文的四個書面、29 個欄位。依 PDF 第 2 頁左半、第 3 頁右半與左半、第 4 頁右半前五欄排列，到「支弟陳懿典譔」為止。館目著錄抄寫年代未詳。第 4 頁右半第六欄另起一段，篇界已記在 JSON。

- `book.json` 保存欄次、圖面連結、疑讀和篇界。
- `book.txt` 可逐欄檢索。 `reading.txt` 按閱讀次序連欄。
- `book.tei.xml` 用 TEI P5 表示來源書面、直欄與疑讀。
